# 会計中の入力保護と営業終了

> 過去の実装計画です。後の依頼で仕様が変わった項目を含みます。現在の仕様は[要件](../requirements.md)、操作は[運用手順](../operations.md)を参照してください。


対象はレビューの1・2・4・5・6。在庫の意味と計算は変更しない。

- 入力中の注文と預かり金を含め、再読み込み・離脱前に確認する。注文下書きは端末内へ営業日・DB世代とともに一時保存し、再開時に復元する。保存済みの会計とは混ぜない。
- 札選択はお釣りの確認画面へ移す。空き札は既定で確保し、必要なときだけ別の空き札へ変更する。同じ番号を選び直した後もEnterで確定できる。
- 札変更は新しい操作として同一トランザクションで注文・旧札・新札・ログを保存する。旧操作や既存バックアップの形式は維持する。
- 未回収の札があれば終了画面に番号を示し、営業終了を止める。ダウンロード開始と利用者による保存確認を区別し、確認後にだけ保存案内を解除する。
- 前日以前の記録からは本日の営業準備を主導線にし、過去の日を開くには日付を確認する。途中の会計・札回収がある場合は先に解消する。
- 専用ポート4273・架空データで回帰試験を追加し、全体試験、レビュー、目視確認後に論理単位でコミットする。

札選択の追記：その後の依頼により、会計欄上部の札を外し、「会計を確定」で札確認ダイアログを開く形へ変更。「この札で確定」で保存し、閉じる場合は未確定のまま戻る。
