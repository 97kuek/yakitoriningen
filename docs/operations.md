# 営業・復旧の手順

初期版の操作手順です。本番の担当者・バックアップ頻度・保存先・紛失札や紙営業の扱いは、本番前に現場で確定してください。

2026年の資料では開催日は11月7日・8日の2日間です。日別の販売時間は17:00まで、企画日時欄には屋台営業終了16:45とも記載されているため、終了時刻は当日責任者に確認してください。

## 営業前

1. 配布された同じURLを、同じブラウザの通常のウィンドウで開きます。プライベートモードは使いません。会計画面は1つだけ開きます。
2. 初めての開催回なら開催回名・営業日・札枚数を入力して準備します。過去の記録があるはずなのに「営業データがありません」と出た場合は、新規準備をしないでください。ブラウザ・プロファイル・URLを確認し、必要ならバックアップから復元します。
3. 日付・価格・保存済みの件数を確認し、「会計を始める」を押します。途中の会計があれば、表示された札と現金を確認してください。
4. 設定の「記録の保護」で「記録を保護する」を押します。許可されない場合もバックアップは必要です。その端末で営業してよいかは本番前に責任者が判断してください。
5. オフライン起動の準備済み表示を確認したうえで、一度通信を切り、アプリを閉じて再度同じURLから開いてください。画面・記録が再表示され、会計・受け渡し・保存ができることを確認します。

動作確認済みの自動試験はmacOS上のPlaywright付属Chromiumです。本番PCのChrome/Edge通常のウィンドウを候補に実機確認してください。その他のブラウザ・OS、停電やOS異常終了への耐久性は未検証です。

## 会計・受け渡し

1. 商品ごとの本数を入力します。価格は最初の1本を入力した時点で固定されます。設定変更後も入力中の額は変わりません。
2. 合計とセット内訳を確認し「会計へ」を押します。保存が終わるまでは現金を受け取りません。満札なら受付を止め、回収を待ちます。
3. お預かり予定額を入力して「お釣りを確認」を押します。入金額・確定操作の保留保存後にお釣りが表示されます。
4. 現金の受領・釣り銭の受け渡しを行い「会計を確定」を押します。保存成功後に待ち一覧へ反映されてから、番号札を渡します。
5. 商品を渡し、実物の番号札を回収してから、注文行のチェックを押します。受け渡しと札回収をまとめて記録し、札を空きへ戻します。札を回収していない注文では押さないでください。たれ・塩だれの希望は受け渡し時などに口頭で確認します。

間違えて完了した直後は「元に戻す」で待ち一覧へ戻せます。札が次の注文へ一度でも再利用された後は、空きに戻っていても取り消せません。売上や別の入力中の注文は変わりません。

完了した行は二度押しを防ぐためその場に残ります。「完了表示を片づける」で一覧を整理できます。注文が多い場合は札番号で絞り込んで探してください。表示を片づけても記録は消えません。

本数入力を消した場合は「元に戻す」で当時の価格と本数を戻せます。新しい本数の入力を始めると、この復元は終了します。お預かり金額を直す場合は「入金額を修正」を押し、受け取ったお金とお釣りを確認してから「入力し直す」へ進みます。

未入金の本数を直す場合は、現金を受け取っていないことを確認して「戻る」を押します。保留を取り消した記録を残し、当時の価格と数量を入力欄へ戻します。「お釣りを確認」の後や再開した会計では、先に入金の有無を確認してください。

受け渡し待ちの本数には調理・包装済み分も含みます。焼くべき本数としては使わないでください。部分受け渡しは初期版では記録しません。

## 設定と注文履歴

- 設定の「商品・価格」で商品を追加・削除し、商品別の通常価格と値下げ価格を入力します。商品名の横のチェックでセット対象を選び、「セット価格」で本数・価格を指定します。セットは対象商品を組合せ自由でまとめ、単品より安くなる場合に使います。
- 価格を変えるときは上部の「値下げ価格に切り替える」または「通常価格に切り替える」を押します。保存済みの商品・セットを使って次の注文から切り替わり、選択中の価格ボタンで確認できます。未保存の商品編集はこの操作では保存されません。商品・セットの編集は別途「変更を保存」で適用してください。入力中・会計済みの注文は変わりません。
- 未保存の設定は、会計・売上や他の設定へ移動しても残ります。再読み込みすると未保存の入力は失われるため、適用する設定は保存してください。
- 設定の「日付・番号札」では、翌日への切り替えと札枚数を変更できます。
- 「集計」では日別と全体の売上を確認し、仕入れ・備品など、開催回全体で使った経費の合計額を登録します。経費が増えたら合計額を更新してください。0円の場合も0を登録します。日付を選ぶと、30分ごとの売上と商品別販売本数の割合をグラフで確認できます。
- 注文履歴は開催回全体・営業日、営業時間10:00〜17:00の30分ごとの時間帯、札番号、状態（未完了・完了・取消）で絞り込めます。未完了には入金前と受け渡し前の注文が含まれます。時刻・札・会計額の見出しで並べ替えます。50件ごとにページを切り替えます。右端のダウンロードアイコンで、絞り込んだ注文を全ページ分まとめてCSVに保存できます。Excelなどで開く一覧であり、復元には使えません。

## 全額取消

履歴の「注文の詳細」で会計番号・日時・札・商品・預かり金・お釣りを確認し、対象の「全額返金」を押します。返金画面でも同じ情報を確認できます。取消理由を入力し、**返金前に**「返金を始める」を押します。保存が確認できてから返金し、現金を照合して取消を記録します。元の会計と返金額は履歴に残り、売上・販売本数から差し引かれます。受け渡し済み商品の返品・廃棄の現場判断は責任者が行ってください。部分返金は扱いません。

返金後、実物の札を回収したら「札を回収した」を押します。まだ回収していない場合は「あとで回収する」を選び、会計画面の札アイコンから回収待ちを確認します。

未入金の保留取消は会計欄で行います。現金受領の有無が不明な場合は、先に照合してください。

## 保存結果が分からない・再起動した

新規注文への入れ直し、現金の再受領、再返金はしないでください。

- 入金の保留は会計欄へ再表示されます。注文内容・当時の金額・札と現金を照合し、同じ注文を確定するか、現金未受領を確認して保留を取り消します。
- 照合待ち操作は、対象内容を確認して同じ記録で再試行します。既に保存済みなら既存結果が返り、同じ売上・返金を二度記録しません。
- 未実行と確認できた操作だけ破棄できます。破棄は照合記録を残します。入金操作を破棄した場合は新しい確定IDで額を再入力できます。
- 復元前の操作は再実行できません。現金・現物を照合して破棄し、復元した注文の画面から必要な記録を行います。復元した保留の入金有無を自動推定しません。
- 保存先を読み取れない場合は営業操作を止め、記録を確認します。DBへ書けない状況でログまで保存できるとは限りません。

紙からの復旧入力機能はありません。紙営業を認める場合の記録様式・照合方法は本番前に別途決めてください。

## バックアップ・閉店・更新

1. 設定を開き、「バックアップを保存」を押します。生成後の内容はアプリ側でも検証しますが、ダウンロード開始だけで別媒体への退避済みとは扱いません。
2. 保存先の `yyyy-mm-dd-yakitori.json` を確認します。アプリでの再選択は不要です。
3. USBメモリ等の別媒体へコピーし、担当者が保存先・読めること・日時を確認します。PC内の別フォルダだけではPC故障に備えられません。
4. 閉店時は未受け渡し・未回収札・保留を照合します。翌日へ営業日を変えてもこれらは消えません。翌日の価格も確認します。
5. アプリ更新は、入力中・保留の会計や未保存の設定を解消してから更新アイコンで適用します。保存済みの記録は残り、バックアップの読み込みは不要です。更新の検出だけで自動再読み込みはしません。

売上一覧は集計・照合用です。売上一覧だけから完全復元はできません。

## 翌年の準備

1. 前年の会計・受け渡し・札回収をすべて終え、途中の注文や確認待ちを解消します。
2. 前年の記録を残したい場合は「バックアップを保存」でファイルを保管します。保存は切り替え操作の必須条件ではありません。
3. 「新しい開催回を準備」を押し、開催回名と1日目の日付を入力して切り替えます。切り替えると前年の記録は画面から消えます。あとから見るには保管したファイルの読み込みが必要です。
4. 商品・価格と札の枚数は引き継がれ、値下げは解除されます。営業前に価格を必ず確認します。古い形式の値下げ設定を使っている場合は、先に通常価格へ戻して確認し、記録を保存し直してください。2日目は同じ開催回のまま日付を変更します。

## 復元・PCの引き継ぎ

1. 会計を止めます。現在の記録も残したい場合は「バックアップを保存」で保管します。
2. 「バックアップから復元」を押してファイルを選び、開催回・営業日・件数・金額・保留・確認待ちの件数を確認します。形式・注文・札・価格・操作結果の不整合があるファイルは拒否します。
3. 「バックアップ内容を確認した」にチェックし、「この内容で再開」を押します。内容を確認している間にDBが変わった場合は、ファイルを選び直します。
4. 一括トランザクションが成功すると新しい世代で営業前確認へ戻ります。途中失敗なら元データを保持します。
5. 札・現金・保留を照合してから再開します。別PCではオンラインでアプリを準備し、同じ手順でバックアップを復元します。複数PCのデータの自動マージはできません。

最後のバックアップ以降の記録をすべて復元できる保証はありません。許容できる損失範囲に合わせた出力頻度・退避先を本番前に決めてください。
