# 営業・復旧の手順

管理する単位は1日の営業です。注文・在庫・経費・バックアップは日別に扱い、前日の記録もアプリ内に残ります。複数の端末やブラウザには自動同期しません。

## 営業を始める

1. [アプリ](https://yakitoriningen.pages.dev/)を同じPC・同じブラウザの通常ウィンドウで開きます。会計画面は1つだけ開いてください。
2. 初回はホームの「営業を準備」で、営業名・日付・札の枚数・商品・価格・任意の在庫を登録します。以前の記録があるはずなのに表示されない場合は、新しく作る前にURL・ブラウザ・プロファイルを確認してください。
3. 翌日は「本日の営業を準備」または「別の日の営業を準備」から日付を選びます。商品・価格・札枚数を引き継いで編集できます。在庫はその日ごとに登録し、値下げは解除して始めます。
4. ホームに表示された営業名・日付を確認し、「会計を始める」を押します。今日と異なる日付を開く場合は確認画面が出ます。
5. 途中の会計や確認待ちがある場合は、画面の案内と現金・実物の札を照合してから続けます。

営業前に、本番PCで一度通信を切り、同じURLを開き直して記録が表示されることを確認してください。ヘッダーの「オンライン」は接続状態です。別端末との同期やバックアップの完了を示すものではありません。

## 会計と札回収

1. 商品の本数を入力します。上から1〜9の商品は数字キーでも1本ずつ増やせます。入力欄を編集中やダイアログ表示中はショートカットが働きません。
2. 合計を確認し「会計へ」を押します。注文と空き札の保存が終わってから現金を扱います。満札なら回収を待ちます。
3. お預かり金額を手入力、または「＋100」「＋500」などで加算します。「ちょうど」も使えます。「お釣りを確認」でお預かり額と確定操作を保留保存します。
4. 現金とお釣りをやりとりして「会計を確定」を押します。開いた札確認画面で番号を確認し、実物と違えば空き札へ変更します。「この札で確定」の保存成功後に、その番号札を渡します。閉じる・Escapeでは確定しません。
5. 商品を渡し、実物の札を回収したら右のチェックを押します。受け渡しと札回収をまとめて記録し、注文を待ち一覧から外します。

「会計へ」→「お釣りを確認」→「会計を確定」→「この札で確定」は、各段階でEnterでも進められます。長押し・金額不足・保存中では先へ進みません。たれ・塩だれの希望は口頭で確認し、画面には記録しません。

本数を直すときは、現金を受け取っていないことを確認して「戻る」を押します。入金額だけ直すときは「入金額を修正」で入力へ戻れます。本数をクリアした直後は「元に戻す」で当時の価格と数量を戻せます。

札回収の押し間違いはパネル下部の「回収取消」で戻せます。売上は変わりません。その札を次の注文で一度でも使った後は取り消せません。未受け渡し本数には調理・包装済み分も含むため、これから焼く本数とは区別してください。

## ホームに戻る・営業を終了する

ロゴか中央の「ホーム」で戻れます。入力途中の本数・お預かり金額は保持します。未保存の設定や経費から移動するときは確認が出ます。ブラウザ自体の終了・再読み込みとは異なります。

営業が終わったら、次の順に進めます。

1. 途中の会計、札回収、未保存の設定を終え、「今日の営業を終了」を押します。
2. 「1日、お疲れさまでした！」の画面で、販売本数と返金を差し引いた売上を確認します。
3. 「JSON・CSVを保存」で、当日のバックアップと注文履歴をダウンロードします。
4. **両方のファイルを確認**してから「保存を確認して終了」を押します。ホームへ戻ります。

| ファイル | 内容と用途 |
|---|---|
| `yyyy-mm-dd-yakitori.json` | 当日の注文・設定・操作履歴。アプリへの復元と日別集計に使う |
| `yyyy-mm-dd-yakitori.csv` | 当日の注文全件。Excelなどで確認する一覧。アプリへ復元する用途には使えない |

ブラウザが複数ファイルのダウンロードを確認する場合は、2ファイルが保存されることを確認してください。設定やホームの「バックアップを保存」はJSONだけです。注文履歴のダウンロードアイコンは、その時の絞り込み・並べ替えに合う全ページ分のCSVです。

17時以降、最新記録の保存確認が済んでいない場合は案内を表示します。保存後に注文・返金・札回収などを記録した場合は、最新の2ファイルを保存し直します。ファイルはUSBなど別の場所にも保管してください。

## 注文履歴と返金

履歴は現在の営業日だけを表示します。時間帯・札番号・状態（未完了・完了・取消）で絞り込み、時刻・会計額で並べ替えられます。時間帯は10:00〜17:00の30分単位です。営業時間外の注文は「すべての時間」で確認します。未完了には入金前の注文も含みます。

行をクリックするか、会計番号にフォーカスしてEnterを押すと詳細を開きます。返金するときは次の手順です。

1. 会計番号・日時・札・商品・お預かり・お釣りを確認し、「全額返金」を押します。
2. 理由を入力し、現金を返す前に「返金を始める」を押します。
3. 保存を確認して返金し、現金を照合して「返金を記録」を押します。
4. 札を回収済みなら「札を回収した」、まだなら「あとで回収する」を選びます。後回しの札は会計画面の札アイコンから回収を記録します。

元の会計と返金履歴は残ります。売上・販売本数から返金分を差し引きますが、在庫は自動で戻しません。部分返金・部分受け渡しは扱いません。返品や廃棄の判断は現場で行ってください。

## 商品・価格・在庫を変える

設定の「商品・価格・在庫」で、商品追加・削除、通常価格・値下げ価格、在庫数を編集し「変更を保存」を押します。商品名の横のチェックがセット対象です。セットの本数・価格は下の「セット価格」で指定します。単品より安い場合に適用します。

上部の「通常価格」「値下げ価格」は、保存済みの設定を次の注文から切り替えるボタンです。編集中の商品は保存されません。入力中・会計済みの価格は変えません。

在庫数には、追加や廃棄を反映した**当日用意した合計本数**を入力します。「残り」は、そこから会計済み本数を引いた数です。会計中の本数も確保済みとして、追加で注文できる本数を制限します。返金分も在庫には戻しません。未登録と0本は区別し、残り20本以下は赤く表示します。会計済み・会計中の本数を下回る在庫は保存できません。

別の日へ切り替える場合は、会計と札回収を終え「別の日の営業を準備」へ進みます。以前の日を開く場合は「保存済みの営業日」を選び「この日の営業に戻る」を押します。

## 営業後に集計する

ホームの「営業後の集計」を開きます。会計を始める必要はありません。当日分を初期表示し、経費合計を入力すると利益を計算します。0円の場合も0を登録してください。

2日分をまとめる場合は「日別のバックアップを集計」から各日のJSONを一緒に選びます。営業名が同じで、日付の重複しないファイルを使います。読み込んだ集計は会計用の記録を書き換えません。

30分ごとの売上棒グラフと、商品別の販売本数の円グラフを表示します。「平均待ち」は会計確定から札回収までの実績です。会計画面は当日の直近10件、日別集計はその日全件の平均を使います。未回収の札の「経過○分」とは異なり、待ち列からの予測ではありません。

## 保存結果が不明・再起動した

同じ注文を新しく入力したり、現金を二度受け取ったり返したりしないでください。

- 途中の会計は再表示された内容・現金・札を照合して続けます。
- 確認待ちの操作は同じ記録で再試行します。保存済みなら同じ結果を返し、二重記録しません。
- 未実行と確認できた操作だけ破棄します。復元前の古い操作は実行できないため、現物を照合してから破棄します。
- 本数の下書きは同じブラウザ・DB・世代・営業日で一時復元します。未保存の設定・経費は再読み込み後には戻りません。

## バックアップから復元する

1. 会計を止め、ホームか設定の「バックアップから復元」を押します。
2. JSONを選び、「バックアップ内容」の営業名・日付・件数・金額などを確認します。
3. 「バックアップ内容を確認した」にチェックし「この内容で再開」を押します。
4. ホームへ戻ったら、札・現金・途中の会計を照合して再開します。

ファイルの日付の記録をバックアップ時点へ戻し、他の日の記録は保持します。別の日の途中会計・未回収札、会計番号の衝突、確認中の記録変更がある場合は復元を拒否します。別PCへの引き継ぎも同じ手順ですが、独立した複数PCの記録を自動統合する機能ではありません。

## 記録の保存場所と保護

記録はこのPC・ブラウザのIndexedDBに保存します。同じURLでも、別のPC・ブラウザ・プロファイルでは保存場所が別です。通常の再読み込みやアプリ更新では記録を消しません。

サイトデータやプロファイルの削除、シークレットモード終了、容量不足によるブラウザの削除、PC・ディスク故障では記録を失う可能性があります。設定の「記録を保護する」はブラウザの自動削除を抑える要求で、バックアップではありません。

設定には使用中の容量と上限の概算を表示します。90%以上なら警告します。会計や未保存設定の操作を中断しないタイミングで表示し、同じ不足状態で繰り返しません。

アプリの更新通知が出たら、入力中の会計や未保存の編集を終えて更新アイコンを押します。更新のためにバックアップを読み込み直す必要はありません。

本番PCのオフライン起動・異常終了・復元と担当者の試用は[検証範囲](acceptance.md)を参照してください。2026年の資料には11月7日・8日、終了16:45と17:00の両表記があるため、当日の終了時刻は責任者へ確認してください。
