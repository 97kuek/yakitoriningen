# 初期版の検証範囲

自動試験を通っても、利用するPCでの耐久性や現場運用の検証を代替しません。

## 自動試験

`npm test` はfake-indexeddbを使い、商品別の通常・値下げ価格、対象商品の最安セット、商品追加・削除後の過去記録、保留・確定・札回収・受け渡し・全額取消、同一ID再試行、異内容拒否、並行割当、価格・営業日変更、経費の再試行と翌日引継ぎ、完了取り消しと札再利用後の拒否、完了・取り消しの一括保存、未登録・0円・赤字の区別、売上・返金・本数の集計、書込失敗、新旧形式のJSON検証、削除済み商品のCSV出力、整合した出力、復元の原子性・世代を検証します。

`npm run test:e2e` はビルド後のPWAをPlaywright付属Chromiumで操作し、実IndexedDBの保存・再起動、価格変更、オフライン再読み込み、JSON出力・読み直し・復元、実トランザクションの`strict`指定、画面幅390px、二重起動、取消の手順、金額欄の二重枠、設定項目・画面の往復での未保存入力保持、未入金の本数修正と旧価格維持、受け渡し完了を元に戻す操作、札番号検索・未受け渡し絞り込みと集計額の維持、経費登録から利益・グラフ表示、開始画面の縦配置と開閉の撤去、同じ途中会計の重複表示抑止、画面復帰時の更新検出と入力保持までを検証します。テストにはサンプルデータだけを使用します。

IndexedDBの耐久性はDexieの`chromeTransactionDurability: 'strict'`、画面は`cache: 'disabled'`とコミット済み結果の購読を使います。設定の根拠は[Dexie公式ドキュメント](https://dexie.org/docs/Dexie/Dexie)です。strictの指定は停電に対する無条件の保証ではありません。

担当者の作業を想定した回帰試験では、同じ場所の150ms間隔の二度押し・Enter反復で別の注文を完了しないこと、札再利用後の取り消し禁止理由、同じ秒・札・内容の注文を会計情報で区別して返金対象を確認できることを検証します。待ち一覧の札検索、12件時の一覧密度、1280×640pxの会計操作、商品が多い場合の商品欄スクロール、注文クリアの復元、預かり金訂正の共通ダイアログ、未保存の商品編集と販売価格切り替えの分離、旧価格との互換性も対象です。

GitHub Actionsは型・単体試験・整形・ビルド・ブラウザ試験が成功した成果物だけを公開します。PRでは公開せず、mainのpushまたはmain上の手動実行だけを対象とします。公開設定は`actionlint`でも検査します。

自動試験の実行コマンドは[CONTRIBUTING.md](../CONTRIBUTING.md)を参照してください。テスト件数は固定せず、試験名と対象の挙動で範囲を管理します。

## 本番PCで行うこと（未検証）

- [ ] OS・機種・ブラウザ・バージョンを記録する。
- [ ] オンライン準備後、通信なしでブラウザを閉じ、同じURLから起動する。
- [ ] 保存完了の表示後、ブラウザを終了・再起動し、件数・金額・注文・札・ログを照合する。
- [ ] 保留保存後、確定直前・直後・画面反映前でアプリを停止し、同じIDの照合から重複なく復帰する。
- [ ] 保存容量不足・復元途中停止で旧状態か完全な復元状態を保持する。
- [ ] OS異常終了・停電について、試験条件・保存完了記録・復帰後記録を比較する。対象条件で欠落0を合格条件にし、欠落した場合は本番利用へ進めない。試験できない条件は未検証として残す。
- [ ] 1,000件・3,000件を仮条件に保存と出力・復元を確認する。性能は合否基準にせず、件数・金額・札・ログの一致を確認する。
- [ ] 実際に別媒体へJSONを退避し、別ブラウザまたは別PCで復元する。
- [ ] 実担当者が開発者の操作なしで、営業開始・通常会計・本数修正・受け渡し取り消し・商品と価格の設定・履歴検索・保留照合・返金・バックアップ・復元を行う。
- [ ] 満札・札紛失・部分受け渡し・紙営業・許容損失・バックアップの頻度・保存先・担当を責任者と合意する。

## 配布

Cloudflare Pagesへ`dist/`を配信します。公開先でのHTTPS・HTTPヘッダー・画像・オフライン再起動は[公開と更新](deployment.md)の手順で確認します。営業では同じオリジンを継続利用してください。別オリジンにはDBが自動で移りません。

2026-10-31にCloudflare Pagesの公開URLで、開始画面・会計・再起動・取消・オフライン・保存した記録の読み込み・共通選択欄・更新確認の試験を実行し、成功を確認しました。HTTPSとHTML・更新用ファイルのHTTPヘッダーも確認済みです。
