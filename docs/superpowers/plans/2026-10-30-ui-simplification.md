# 会計画面の整理

目的：説明文を読まずに、本数・金額・札番号と次の操作を見分けられるUIにする。

- [x] 会計と受け渡しを主画面とし、重複した見出し・説明・常時警告を削る。
- [x] 金額と数量を大きく、操作はSVGアイコンと短いラベルで示す。提供された看板に合わせ、黄色（#ffdf58）・朱赤（#be3327）・墨色（#29281f）・紙色（#fffef7）、基本の操作には墨色、返金・エラーには赤だけを使用。提供された看板を参照して生成したロゴをヘッダー、生成した屋台の絵を開始画面、空の待ち一覧は小さなアイコンと短い文にする。日本語システムフォントを使用する。
- [x] 保留保存後は支払い欄へ切り替える。現金の移動前の保存、二重登録防止、再開時の照合は維持する。
- [x] 開始確認・設定・データ画面の説明を短くし、補足は折りたたむ。yomiyasuの意味・条件の保持に従い、必要な確認を単なる短縮で失わない。
- [x] ブラウザ試験で会計への切替、釣銭、返金・復元、スマホ幅、キーボード操作を確認し、画像でレイアウトを点検する。

追加依頼を受け、受け渡し・札回収をまとめて記録するcomplete操作を追加した。物理状態は別々のフラグで保持し、同一トランザクションで保存する。ユーザーの最終指示により個別操作メニューは画面から外した。価格計算は変更していない。ユーザーからmainへのコミット・pushの指示を受けたため、最終確認後に実行する。Web公開は対象外。

## 最終確認

単体・保存試験55項目。ブラウザでは開閉時の位置・入力・フォーカス保持、専門語の排除、履歴の簡略化、受け渡し、失敗時の案内、キーボード操作を確認する。実ユーザーの試用は別途必要。
